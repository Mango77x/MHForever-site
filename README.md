# MHForever site

Source of the website for [MHForever](https://github.com/Mango77x/MHForever), an unofficial native PC port of
*Monster Hunter Freedom Unite* made by static recompilation.

**The project, the downloads and the issues live in the main repository: https://github.com/Mango77x/MHForever**

This repository only holds the static site (plain HTML, CSS and JavaScript, no build step). Every push to `main`
publishes it with GitHub Pages.

## Working on it

Open `index.html` in a browser. The page text is English in `index.html`; the Spanish and Japanese translations are in `app.js`. English is the default; the page switches to Spanish or Japanese when the browser asks for them, and visitors can change it with the language buttons.
The site contains no game assets, only original artwork (logo and launcher replica).

Fonts: Sora and Manrope, both under the SIL Open Font License (see `fonts/`).
